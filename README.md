## miniGit, no tracking · 186KB
miniGit is a zero-dependency tool designed to eliminate the tracking risks associated with traditional Git platforms. 
Built for activists and users operating in high-risk environments, miniGit is a fully offline source-management tool under 200 KB in size. Unlike GitHub, 
it requires no server, no account, and leaves no remote commit history. 
It enables local source-code review, hash verification, static suspicious-code scanning, and offline file transfer via Bluetooth and ultrasonic communication.
